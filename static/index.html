🚦 Smart City Traffic Forecasting Dashboard

Traffic Peak Forecasting System for Government Planners

👋 Welcome to Smart City Traffic Forecasting Dashboard

Get started by clicking the buttons below in order:

  1. Load & Preprocess Data - Loads and cleans your traffic dataset
  2. Generate EDA Plots - Creates exploratory data analysis visualizations
  3. Train Models - Trains forecasting models (takes 5-10 minutes)
  4. Generate Forecasts - Creates 30-day traffic predictions
  5. Evaluate Models - Calculates performance metrics (MAE, RMSE, MAPE)
  6. Refresh Dashboard - Reloads all data and displays results
  7. Show All Sections - Displays all results at once

💡 Tip: Each button will show only its relevant output section. Use "Show All Sections" to view everything together.

📊 Model Performance Metrics

📈 Click "Evaluate Models" button to calculate and display performance metrics.

Metrics include: MAE (Mean Absolute Error), RMSE (Root Mean Squared Error), and MAPE (Mean Absolute Percentage Error)

🔮 Traffic Forecasts (Next 30 Days)

🔮 Click "Generate Forecasts" button to create 30-day traffic predictions.

Forecasts will be displayed as interactive charts for each junction.

📈 Exploratory Data Analysis

📊 Click "Generate EDA Plots" button to create exploratory data analysis visualizations.

Plots include: Traffic Trends, Working Days vs Holidays, Peak Hours, Seasonal Patterns, and Weekday Patterns
